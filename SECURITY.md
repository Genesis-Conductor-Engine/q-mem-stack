## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please report it to us as quickly as possible using one of the following options:

- **GitHub Security Advisories:** Open a private security advisory from the repository's **Security → Advisories** page. This is the preferred reporting method.
- **Email:** Alternatively, send a detailed report to the project maintainers at Genesis-Conductor-Engine.

When reporting a vulnerability, please include:

- A description of the issue and the affected component(s)
- Steps to reproduce, including any proof-of-concept code or configuration
- The impact you believe the issue may have
- Any relevant logs, screenshots, or environment details (OS, versions, etc.)

We ask that you **do not** disclose the vulnerability publicly until we have had a reasonable opportunity to investigate and prepare a fix.

### Response and Disclosure Process

- We aim to acknowledge receipt of vulnerability reports within **3 business days**.
- After initial acknowledgment, we will provide updates at least **every 7 business days** until the issue is resolved or we determine it is not a security vulnerability.
- If we confirm the vulnerability, we will work to develop and publish a fix as soon as reasonably practical, taking into account the severity and complexity of the issue.
- Once a fix is available, we may publish a security advisory and, where appropriate, credit the reporter (unless you request to remain anonymous).
- If we determine that a reported issue is not a security vulnerability, we will explain our reasoning to you.
