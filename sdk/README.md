# Genesis Thermal Bridge SDK

This SDK provides the foundational modules for the Genesis Thermal Bridge initiative.

## Modules
- `energy_credit_ledger.py` — reusable energy credit ledger.
- `extropic_bridge.py` — mock hardware bridge interface.
- `client.py` — orchestration client for simulations and integrations.

## Install (editable)
```bash
pip install -e ./sdk
```
